# Hi, I build tools for the trades

Plumber in Ottawa-Gatineau. I use AI to build practical software for the trades: tools I need on real jobs, built and tested against real plans.

## Projects

**[Plan Measure](https://github.com/lorplace/plan-measure)** - [live app](https://plan-measure.pages.dev)
Free, browser-only takeoff tool for construction plans. Opens PDF, image, DXF and DWG files, sets scale from a known dimension, and measures lengths, areas, counts and pipe runs. Includes a sleeve tool that locates each sleeve from gridlines and walls and exports a sleeve list. Works on desktop and phone with nothing to install.

**[Lane Siege](https://github.com/lorplace/lane-wars-td)** - [play it](https://lane-wars-td.pages.dev)
A 3D tower-defense game in the browser (Three.js), in the spirit of the Warcraft III map Line Tower Wars.

**[AgentLens](https://github.com/lorplace/agentlens)**
Scans a Shopify store and scores how visible and usable it is to AI shopping agents, with specific fixes.

## What I focus on

- Turning field problems (takeoffs, sleeving, layout) into simple tools that work on site.
- Directing AI to build software, then testing it hard against real-world drawings and measurements.
- Construction tech and AI for the trades.
